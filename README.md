# Image Mask Editor

This edit helps to correct mask predicted by segmentation model to feed the manual corrected data to next version of the model.

These are the following feature it supports:
- Load images and mask PNGs, with masks matched by filename or selected manually.
- View masks as an adjustable overlay or side by side with the image.
- Draw and erase mask regions with an adjustable brush and circular cursor preview.
- Scroll to change brush size; use Ctrl+scroll to zoom toward the pointer.
- Undo the last stroke with Ctrl+Z; clear the mask with Alt+E.
- Navigate images with A/D.
- Save masks as PNGs with Ctrl+S, using a remembered save folder.
- Customize mask tint and opacity.
